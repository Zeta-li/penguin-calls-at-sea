# 三个原始示例

这三段 Supplementary 5 录音取自 Andréa Thiebault 发布的 *African penguins sea-surface vocalisations and playback experiment at sea*，文件保留原始字节。每种声型各一例。记录没有将 108 行测量逐条连接到原始波形的标识。[原始数据与作者](https://doi.org/10.5281/zenodo.21376649) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

脚本给每段示例施加数字噪声，用已知原声测量表征保真度。每个种子对应的噪声实现只用于检验算法对遮蔽频带的反应。表中的样本量始终是三段录音。
